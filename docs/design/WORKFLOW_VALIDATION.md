# ผลตรวจทีมและ skills

ตรวจวันที่ 2026-10-03 ตามเวลาไทย งานรอบนี้เปลี่ยน workflow/เอกสาร/skills
ไม่ได้แก้กฎ ภาพในเกม APK หรือ deploy บริการออนไลน์

## สิ่งที่ตรวจจริง

- Skill files 6 ไฟล์มี frontmatter `name`/`description` ถูกต้อง ชื่อตรง directory
- ลิงก์ภายในชุด skill/ทีม/brief/handoff ตรวจว่าปลายทางอยู่ใน repository และมีจริง
- เอเจนต์อิสระอ่าน workflow แล้วเดินผ่านคำขอ 4 แบบในตารางด้านล่าง
- ตรวจการแบ่งเจ้าของไฟล์ ข้อตกลงที่ยืนยัน/เสนอ และสถานะ concept/runtime/device
- พบกฎเดิมใน `AGENTS.md` ที่สั่งใช้ placeholder; แก้เป็น original authored art
  โดย placeholder ใช้ทดลองและไม่ผ่านคำขอด้านงานภาพ
- รวมคำถามไว้ที่ coordinator คนเดียว จำกัด 1–3 ข้อต่อรอบรวมทุกบทบาท
  เอเจนต์ย่อยส่งข้อเสนอแทนการถามผู้ใช้ซ้ำ

## ตัวอย่างคำขอที่เดินผ่าน

| คำขอแบบผู้เล่น | งานย่อยที่เลือก | ผลที่ต้องส่ง | APK |
|---|---|---|---|
| “เกมมีแต่ตัวหนังสือ อยากให้ตัวละครเด่น” | ภาพ, native integration, ตรวจประสบการณ์ | ฉากเล่นได้ที่มีตัวละคร/ศัตรู/ภาพการ์ดจริง พร้อมภาพก่อน/หลังและ feedback | ใหม่เมื่อรวมงานในเกม |
| “คอมโบเสี่ยง ๆ ที่ใช้ถูกแล้วสะใจ” | mechanics/content, ภาพ/feedback, native, review | สองเส้นทางเล่นได้: เสี่ยงเพื่อ payoff และทางปลอดภัย เห็นต้นทุน/ผล/ข้อแลกเปลี่ยน | ใหม่เมื่อเปลี่ยนเกม |
| “เก็บเซฟออนไลน์งบน้อย ไม่รู้ต้องทำยังไง” | native cloud/setup, reviewer | ใช้ adapter/schema เดิม ขั้นตั้งโปรเจกต์สั้น ๆ และ check/backup/restore เมื่อเชื่อมจริง | ใหม่เมื่อใส่ config/แก้ code; คู่มืออย่างเดียวไม่เปลี่ยน |
| “สร้างทีมให้เข้าใจผมไม่ต้องสั่งซ้ำ” | brief/director, skill authors, independent review | ความจำ บทบาท skill files, handoff และตัวอย่างรับคำขอ | ไม่เปลี่ยนในรอบ workflow |

คำขอภาพอาจถามว่าชอบภาพ A/B หลังมีภาพจริงให้เทียบ ส่วนคอมโบและ workflow
เริ่มได้จากความต้องการที่ชัดอยู่แล้ว ไม่มีการให้ผู้ใช้ตั้ง schemas, numbers หรือ engines
การทดลองมี default ที่ย้อนกลับได้และระบุว่าเสนอ ยังไม่บันทึกเป็นคำอนุมัติจากผู้ใช้

## ขอบเขตของหลักฐาน

นี่คือการตรวจไฟล์/ลิงก์และ semantic walkthrough โดยเอเจนต์อิสระ ไม่ใช่การทดลอง
กับผู้เล่นกลุ่มตัวอย่าง ไม่ใช่ benchmark โมเดลหรือการทดสอบเกมรอบใหม่
ไม่ได้รับรองว่าจะเข้าใจทุกความคิดทันที; การส่งผลให้ดูและรับคำแก้ไขยังจำเป็น

`AGENTS.md` และ saved cloud startup อ่าน skill files โดยตรงได้ จึงไม่ขึ้นกับการ
เพิ่มชื่อใน global catalog; ยังไม่ได้ตรวจการ restore/load ใน cloud task ใหม่
บันทึก startup draft ไม่ใช่ publish/apply snapshot หรือเปิด agents ค้างอัตโนมัติ
ผลเดิมของเกม/APK/Supabase อยู่ [VALIDATION](../VALIDATION.md)
